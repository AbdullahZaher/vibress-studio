# Versioned compatibility fixtures

`compatibility-v1.json` contains synthetic, source-controlled examples. It does
not contain production articles, credentials or private media URLs. Its fixture
manifest version is independent of each Studio document's schema version.

The library includes mixed Arabic/English text, legacy cards, future nodes and
document versions, envelope extensions, tables/lists/code, all thirteen built-in
card payloads, corrupt nodes and unsafe HTML. Large/deep/cyclic inputs are
generated by the resource-limit tests rather than committed as huge files.

Run `pnpm test:roundtrip` and `pnpm test:security`. The host comparison uses the
same persisted-document fixtures from an immutable host commit:

```sh
pnpm verify:host-compatibility --host ../vibress --ref COMMIT_SHA
```

Unknown content must survive persisted JSON round trips. Rendering can have
documented fallbacks; editing must refuse content that its runtime cannot retain.
Add a fixture before fixing a confirmed compatibility defect, retain historical
inputs, and document intentional output differences. Only authorized, anonymized
production samples may be added in a later review.
